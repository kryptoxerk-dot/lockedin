How it works

Fees in.
Locks out.

The same four steps repeat for as long as $LOCKEDIN trades. No staking, no claiming, nothing to sign up for.

  1. 1

    Trading pays creator fees

    pump.fun charges a creator fee on every trade. The split is fixed at launch and frozen: half to the buyback vault, half to the creator.

  2. 2

    The vault buys

    Once the vault can cover a buyback plus account rent, the keeper buys $LOCKEDIN on the bonding curve, or on PumpSwap after graduation.

  3. 3

    Locked in a keyless wallet

    The whole purchase moves to a brand-new address with no private key. The program has no instruction that moves locked tokens.

  4. 4

    One more locked holder

    The on-chain counter goes up by one. Supply stays the same: this is a lock, not a burn.

Derive a holder address yourself +

Each lock's address comes from the mint and the lock number. Reproduce them independently:

import { PublicKey } from "@solana/web3.js";
const program = new PublicKey("Awaiting deployment");
const mint = new PublicKey("Awaiting launch");
function holder(index) {
  const i = Buffer.alloc(4);
  i.writeUInt32LE(index);
  return PublicKey.findProgramAddressSync(
    [Buffer.from("hold"), mint.toBuffer(), i], program
  )[0];
}
// PublicKey.isOnCurve(holder(0).toBytes()) === false
